## 三、 人工筛选、修改、重构与二次创作过程（⚠️ 竞赛重点核验项）

### 1. 人工筛选与内容把关
* **AI 生成了哪些候选方案**：GPT Image 按 `DESIGN.md` 的 5 段 Prompt 反复出图，每张界面均有多版候选概念图（含不同构图、配色与元素密度）。
* **筛选逻辑（团队共同执行）**：
  1. **美学标准**——以宋代水墨极简为准绳，**剔除**带科技感发光渐变、大圆角卡通感、信息过载、山水元素喧宾夺主的方案；
  2. **文化准确性**——逐条核对《元素映射表》：卡通波点背景必须换成宣纸质感、粉色卡通 Logo 必须换成**朱砂篆刻方印【華風】**、「登录/注册」必须换成**「入席/缔约」**、按钮文案必须为**「落座入席」「完成缔约」**；
  3. **工程可落地性**——概念图中无法落地的部分（如无规则栅格、文字排版失真、控件层级混乱）不予采纳，改由 `DESIGN.md` 第 3 节的栅格与圆角规范（左右留白 16~20px、1px `#E2D9C8` 描边、圆角 8~12px）重新约束。
* **舍弃内容**：多版"重彩描金/繁复纹样"方案（与留白美学冲突）、一版"四栏底部导航"方案（与团队三栏信息架构不符）、多版字色过淡导致正文可读性不足的方案。
* **人工冻结的产出**：5 张界面设计图 + 10 条色谱 Token（`#F5F0E6` 等），作为全组共享的视觉基准（已固化为 `styles/variables.less`）。

### 2. 视觉素材的人工二次加工（本次提交涉及）
* **裁切与定位**：人工核对首页设计图的像素坐标，确定四雅插画的实际包围盒（如青瓷瓶插画定位于 900×1600 画布的 `x 245~450 / y 800~1058`），避免误裁到标题与按钮区。
* **去杂质**：切图边缘残留的设计稿标题文字（「道」「骨」「事」等红字残影）由人工判定并**用卡片底色覆盖抹除**。
* **透明化处理**：底栏三个器物图标按"以四角底色为基准做 alpha 阈值化"处理成**透明底遮罩**，从而可被 CSS `mask-image` + `currentColor` 着色——这一步是人工重绘思路（把一次性位图改造为可随主题变色的组件资产），而非直接搬用图片。
* **配色统一**：所有插画与图标统一纳入上文 10 条 Token 体系；卡片描金边、回纹角、印章均为**人工用 CSS 绘制**（`.gu-frame()` 混入），非图片贴图。
* **体积控制**：单图压缩至 ≤200KB（背景 159KB、四雅插画各约 20KB）。

### 3. 代码与系统的手工重构与编写（核心）
* **AI 提供的初版**：AI 编程助手依据 TRD/设计稿与白名单，产出 5 个文件的初版结构与样式（含四雅卡片的布局与诗签卷轴雏形）。
* **人工重构与把关（逐项执行、非无修改搬用）**：
  1. **需求与约束先行**：由本人（成员 B）确认任务边界——只动白名单 7 项文件、`App.jsx`/`global.css`/`variables.less`/`utils/rem.js` 全局冻结，AI 初版任何越界改动一律回退；
  2. **逐块对照设计稿验收**：对题头、诗签卷轴、时令物候栏、四雅宫格、底栏三栏五个区块逐块比对，发现并纠正了"卡片做成图上文下"（设计稿为**左文右图**）、"四雅标题误用墨黑"（应为**朱砂红**）、"底栏激活态用方块"（应为**朱砂横线**）、"背景被裁切"（应**整幅铺满**）等 7 处偏差；
  3. **专题修复既有工程缺陷（人工定位）**：
     * 底栏高亮不同步——原实现用 `window.location.pathname` 快照，刷新/前进后退后高亮错乱 → 改为 `useLocation()` 实时派生；
     * 整页横向溢出 23px——底栏 `box-sizing: content-box` 叠加左右内边距所致 → 改 `border-box`；
     * 网格被图片撑宽——为雅席卡加 `min-width:0` 与 `grid-template-columns: repeat(2, minmax(0,1fr))`；
  4. **Token 化审查**：人工核查全部样式无硬编码主色，一律引用 `variables.less`；
  5. **真机视口实测**：通过 Chrome DevTools Protocol 设备模拟，在 `390×844` / `430×932` 视口实测 `rem=39px`、`horizontalOverflow=false`、底栏图标加载正常、`Console 报错 0`、四雅卡尺寸一致（176×121），并据此修正了此前用普通截图误判的"右侧溢出"结论。
