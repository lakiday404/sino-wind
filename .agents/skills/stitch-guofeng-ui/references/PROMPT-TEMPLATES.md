# 逐屏提示词模板（云山竹简 · 华风雅集）

> 用法：复制对应屏的模板 → 每条提示词前都粘上 `SKILL.md` 第 2 步的 `DESIGN SYSTEM (REQUIRED)` 块 → 按需替换 `{{}}` 占位 → 投喂 Stitch。
> 屏幕路由与文案以代码现状为准（`frontend/src/pages/`），`DESIGN.md` 的早期四栏底栏方案已被现实现的三栏取代。

## 1. 入席（登录页，`/login`，组件 `AuthPage.jsx`）

元素替换依据 `DESIGN.md` §二.1。

```markdown
一位雅士前来入席，界面沉静、可信、有金石之气。

1. **背景**：微黄手工宣纸，四角淡若游丝的宋代山水水墨晕染
2. **顶部**：朱砂篆刻方印【華風】；主标题「云山竹简 · 华风雅集」；副题「格物致知 · 品茗论道 · 与千古先贤共赏风雅」
3. **切换印符**：朱砂滑块，「入席」为激活态、「缔约」为未激活态，滑动指示条带 0.3s 缓动
4. **表单卡片**：绢帛玉白，圆角 10px，1px 古纸线界；两个输入位 —— 「请输入雅士手机号或信箱」、「请输入通行密押」
5. **主按钮**：朱砂长条按键「落座入席」，象牙白字，微金内边线，无外发光
6. **次要入口**：「以文会友 · 快捷入席」，配古铜/黛色古典图标
7. **页脚**：「入席即代表您遵循《雅集清规》与《文墨共识》」，淡墨小字
```

## 2. 缔约（注册卡片，与入席同页滑动切换，`/login`）

```markdown
一位新雅士立约缔盟，与入席页同源同色，仅内容不同。

1. **背景与顶部**：与「入席」页完全一致（同一张宣纸、同一枚【華風】朱砂方印）
2. **表单卡片**：四个输入位 —— 「拟定雅号（如：青莲居士、东坡散人）」、「请输入手机号或信箱」、「请输入验真码」（右侧为水墨草书风验真字迹图）、「请设置通行密押」
3. **主按钮**：朱砂长条按键「立约缔盟」
4. **约束**：与登录页保持同一栅格与间距，仅字段数量不同
```

## 3. 雅集大厅（首页，`/home`）

结构与文案依据 `frontend/src/pages/Home.jsx`。

```markdown
雅士步入雅集大厅，先见诗签与岁时，再见四大雅席入口。

1. **顶部题头**：「云山竹简」标题 + 朱砂小印【华风】；副题「读千年风雅 与君共此山河」
2. **每日诗签**：两端木轴的横向卷轴卡片，正文分两行居中（如「山水之乐，/ 在乎山水之间也。」），句末落朱砂小印【醉翁】，下方出处「—— 欧阳修《醉翁亭记》」；卷轴右侧一幅淡墨山水小图
3. **岁时物候栏**：三列 —— 左列城市「杭州」+ 线性下箭头 + 天气温度「24°」与「多云 空气优」；中列「农历 三月廿六」「乙巳年 庚辰月 丙午日」；右列节气「清明」+ 朱砂小印【华风】+ 「万物清明 / 春和景明」
4. **四大雅席入口**：2×2 宫格卡片，每张为「左侧文字 + 右侧水墨器物小图」结构，卡片圆角 10px、1px 古纸线界：
   - 博古识器（识古今之器 / 赏华夏之美）
   - 先贤论道（与李白苏轼 / 共话千年风骨）
   - 飞花诗令（以诗会友 / 飞花成令）
   - 四般闲事（焚香品茗 / 插花弄趣）
5. **底部导航**：三栏（雅集 / 观藏 / 书斋），「雅集」为激活态：朱砂图标 + 朱砂下划线；底栏顶部 1px 描金线与两端回纹描金角
```

## 4. 观藏 · 古友论道（`/ai`）

```markdown
雅士立于观藏殿堂，四位千古知己在廊下列席相候。

1. **顶部题头**：天青瓷到宣纸的雅致渐变，标题「古风古友 · 跨越千古逢知己」，副题「与先贤知交煮茶对坐，笑谈风月古今」
2. **先贤横向画廊**：李白（执酒壶）、苏轼（捧茶盏）、王阳明（心学宗师）、李清照（荷畔词宗）四位先贤的圆形头像卡，选中者朱砂描边
3. **功能卡片**（竹简式，左文右图）：
   - 古友论道：与千古知己倾心畅谈，探讨诗酒意趣与心学修身
   - 诗韵唱和：切磋诗词对仗、飞花令、对联拆字
   - 抚琴听音：古风拟人语音交互，伴古琴流水清音
4. **底部导航**：三栏，「观藏」为激活态
```

## 5. 先贤论道对话页（`/ai-chat`）

```markdown
与先贤对坐论道的水墨对话界面，全屏无底栏。

1. **顶部栏**：返回箭头（线性矢量图标）+ 当前先贤雅号与其一句人设断句 + 头像
2. **对话区**：气泡为宣纸白（雅士）与霁蓝黛青（先贤）两色；气泡圆角 10px，无阴影堆叠；先贤气泡左侧带头像
3. **输入区**：胶囊输入位「向先贤请教…」+ 朱砂圆形发送钮；键盘弹起时输入区贴底
4. **禁止**：现代社交软件的蓝色气泡、渐变头像环、emoji 表情按钮
```

## 6. 墨隐书斋（个人中心，`/mine`）

```markdown
雅士回到自己的书斋，查看修持成果与藏品。

1. **顶部题头**：素雅竹林书斋，印章式头像框（朱砂底 40×40、圆角 6px、金线描边）+ 雅号「云山居士」+ 境界徽章【修身三重 · 翰林待诏】+ 座右铭「格物穷理，知行合一」
2. **修持四维数轴**：一行四项，图标在上、数字在下 —— 鉴宝藏器 / 论道问策 / 诗笺摘录 / 文风品阶（数字取真实计数，无数据显示占位而非编造）
3. **藏品与墨卷**：两张竹简卡片 —— 琅嬛藏诗阁、博古鉴宝录，右侧线性右向箭头
4. **书斋清规**：四行列表 —— 印信与密押设置、岁时节气物候提醒、雅集问难答疑、整装离席（朱砂文字）
5. **底部导航**：三栏，「书斋」为激活态
```

## 7. 古诗词天地（`/poem`）

依据 `TRD_PHASE2.md` §3.1。

```markdown
雅士在宣纸诗卷前品读千古名篇。

1. **顶部**：搜索栏（线性放大镜图标 + 「检索诗人或诗名」占位）+ 返回箭头
2. **诗卷主体**：宣纸卷轴版式，诗题居中、朝代与诗人以朱砂小印标注，正文对仗断句分行居中，字距微放
3. **诗境赏析**：可折叠面板，展开后以淡墨小字呈现先贤品鉴
4. **底部四动作**：重研墨宝（刷新线性图标）/ 摘录入卷（收藏线性图标，点击触发朱砂印章下压光效）/ 诗境赏析（书卷线性图标）/ 返回雅集
5. **约束**：四个动作全部使用线性矢量图标，禁止位图与字符箭头
```

```markdown
3. **空状态**：留白式雅意构图 + 「尚未摘录，去古诗词天地择一首入卷」引导语与跳转入口
```
