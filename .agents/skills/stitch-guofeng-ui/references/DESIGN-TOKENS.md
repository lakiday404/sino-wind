**用色纪律**

- 强调色只有一个（朱砂）。金色只做「描边与徽章」，不做大面积填充。
- 严禁引入品牌外色：蓝紫 AI 渐变、科技霓虹、玻璃拟态一律不进稿。
- 不使用纯白 `#FFFFFF` 作整屏背景；需要更亮表面时用绢帛玉白 `#FAF7F0`。

## 2. 质感与意境

- **纸张肌理**：极淡的手工宣纸/竹纸纤维暗纹，可复用 `frontend/public/assets/common/bg_guofeng.jpg` 与 `assets/home/bg-paper.jpg`。
- **印章篆刻**：朱砂方印 + 回纹描金边，是全站品牌锚点，反复复用而非每屏新造。
- **书法骨骼**：标题与诗词用宋/楷体系，字间距微放 `0.5px ~ 1.5px`。
- **留白美学**：宋代克制，画面舒展；信息密度低于通用 SaaS 界面。

## 3. 字体体系（对齐现有实现）

| 用途 | 字族栈 | 现状依据 |

| 国风小标题、按钮文案 | `'Kaiti SC', 'STKaiti', 'KaiTi', serif` | `home.less` / `minePage.less` |

## 5. 关键组件规格

| 组件 | 规格 |
| :--- | :--- |
| **朱砂印章** | 40~50px 方形，圆角 4~6px，朱砂底 + 象牙白篆刻字；全站复用同一组件 |
| **主按钮** | 朱砂长条按键，象牙白字，微金内边线，无外发光 |

| **卡片** | 绢帛玉白底 + 1px 古纸线界 + 纸感微投影（`fade(#3a2f1d, 7%)` 级别的极淡阴影） |
| **输入位** | 标签在上、输入位在中、错误文案在下（`#9E2A2B`）；占位文字用淡墨 |
| **底部导航** | 三栏：雅集 / 观藏 / 书斋；图标 `0.6rem × 0.48rem`，激活态朱砂图标 + 朱砂下划线 |
| **每日诗签** | 横向卷轴，两端木轴，正文楷体竖排或优雅横排，落款印章在句末 |

## 6. 动效意图（Stitch 出静态稿，此节供落地实现）

- 只动 `transform` 与 `opacity`，不动 `top/left/width/height`。
- 印章类交互：下压 `scale(0.98)` 或 `translateY(-1px)` 的触感反馈，**无**外发光。
- 摘录盖章：朱砂印章下压光效 + Toast「已摘录入书斋」。
- 列表入场：交错延迟（`animation-delay: calc(var(--index) * 60ms)`），不做瞬间齐现。
- 舒缓为先：过渡 `0.2s ~ 0.3s ease`；不追求炫技编排。

## 7. 单位与实现约定

- 动态 `rem`：`frontend/src/utils/rem.js` 把视口宽度十等分，但**先把视口夹在 320~540px 之间**（`min(max(clientWidth, 320), 540)`），故 `1rem = clamp(视口宽, 320, 540) / 10`。375px 宽时 1rem = 37.5px，540px 及以上恒为 54px。出图按 px 描述，落地时按此换算为 rem。
- 颜色、圆角、边框一律走 `variables.less` 变量，不在 Less 里重复硬编码十六进制。
